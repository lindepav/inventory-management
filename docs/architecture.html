Factory Inventory Management System

Architecture overview: Vue 3 single-page app, FastAPI backend, in-memory JSON data. No database.

System Architecture

Three tiers, two processes. The browser talks to the API directly over HTTP.

Frontend - localhost:3000

Vue 3 SPA (Vite)

Composition API, client-side routing with Vue Router, custom SVG charts, English and Japanese UI.
App.vue (shell + nav) Views: Dashboard, Inventory, Orders, Spending, Demand, Reports Modal components FilterBar Composables: useFilters, useI18n, useAuth api.js (axios client)
HTTP / JSON (axios) · CORS open to all origins
Backend - localhost:8001

FastAPI (server/main.py)

REST endpoints under /api. Query-param filtering, Pydantic response models, auto docs at /docs.
/api/inventory /api/orders /api/demand /api/backlog /api/dashboard/summary /api/spending/* /api/reports/*
Python imports (loaded once at startup)

Data Flow

How a filter change on the dashboard reaches the screen.

Filter changeUser picks a period, warehouse, category or status in FilterBar.
Shared stateuseFilters holds the four filters as singleton refs.
API callView calls api.js, which sends non-"all" filters as query params.
Filter in memoryFastAPI filters the loaded lists by warehouse, category, status and month.
ValidatePydantic models shape the JSON response.
RenderRaw data lands in refs; computed properties derive totals and chart data.

Key Patterns

Filters

  • Four filters: Time Period, Warehouse, Category, Order Status
  • Inventory ignores month (no time dimension)
  • Quarter filters map to months via QUARTER_MAP

Reactivity

  • Raw API data in ref
  • Derived values in computed
  • Loading and error states per view

Cross-cutting

  • useI18n with locales/en.js and ja.js
  • useAuth supplies a mock current user and tasks
  • Custom SVG charts, no chart library

Observations

Gaps found while reading the code.

  • api.js calls /api/tasks and /api/purchase-orders, but main.py does not define those routes. Pydantic models and purchase_orders.json exist for purchase orders.
  • views/Backlog.vue exists but is not registered in the router.
  • The API base URL is hard-coded to http://localhost:8001/api in api.js, and CORS allows all origins.
